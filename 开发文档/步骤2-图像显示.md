# 1. 先说一个坑（不然你又会看到"图片被拉长"）

一开始我用最省事的写法：

```csharp
HalconView.SetFullImagePart(image);     // 让整幅图自适应控件
HalconView.HalconWindow.DispObj(image); // 画出来
```

**实测结果是被拉伸的**：

| 场景 | 画面比例 | 结论 |
|---|---|---|
| 普通窗口首次显示 | **1.882**（= 窗口比例） | ❌ 拉伸 |
| 最大化之后 | 1.333 | ✅ 正确 |
| 再翻下一张 | **2.199** | ❌ 又拉伸 |

原因：控件的 `HKeepAspectRatio="True"` **只在"控件尺寸变化"时才生效**；初次显示、以及我们主动 `DispObj` 的时候它不管，
于是图像被直接铺满窗口 → 长宽比就崩了。（你之前说"图片比例好像崩了"就是这个。）

**正确做法：自己算显示区域（part）**，就 20 行数学，**不需要加缩放拖动**：

```
part 的宽高比 = 窗口的宽高比，且刚好"包住"图像
  → 图像比窗口"宽"：part 宽 = 图宽，part 高 = 图宽 ÷ 窗口比例      （上下留黑边）
  → 图像比窗口"高"：part 高 = 图高，part 宽 = 图高 × 窗口比例      （左右留黑边）
再 set_part(part) + disp_obj(图) 就肯定不变形
```
实测：普通窗口 906×679、最大化 935×701、翻下一张 935×701 → **比例全是 1.334** ✓

# 2. 三个功能的思路

## 功能① 图片怎么从磁盘到屏幕

```
选文件夹 / 点下一页
  → MainViewModel.ShowCurrent()
      → LoadImage(item)                       【VM 的活】
          → CurrentImage?.Dispose()           释放上一张（native 资源）
          → new HImage(item.FilePath)         = read_image
          → CurrentImage = image              ★ 赋值 → 触发属性变更通知
  → View 收到 PropertyChanged(CurrentImage)   【View 的活】
      → ShowCurrentImage() → FitAndDraw()
          → GetWindowExtents 取窗口像素尺寸
          → 算 part（上面那 20 行）
          → SetPart + ClearWindow + DispObj
```
**为什么读图放 VM、画图放 View**：读图是业务（以后换显示方式也照样要读）；`DispObj` 必须拿到控件里的 `HalconWindow`，是纯界面动作。

## 功能② 怎么保证不变形

就是第 1 节那套 part 数学。要点：
- **part 的宽高比必须等于窗口宽高比**（这是"不变形"的唯一条件）
- part 比图像大的部分落在图像外 → 显示成窗口背景（黑边），所以别怕 part 算出来比图像大
- **窗口大小变了要重算**（`HalconView.SizeChanged` → 重新 `FitAndDraw()`），否则最大化后就变形了
- 因为比例我们自己管，XAML 里把控件的 `HKeepAspectRatio` **关掉**，免得它跟我们抢着算

## 功能③ 换图 / 翻页怎么跟着变

- View 在构造函数里订阅 `_viewModel.PropertyChanged`
- 只有 `CurrentImage` 变了才重画（别的属性变化不管）
- 用 `_shown` 记住"已经画过的对象"，同一张不重复画（避免无谓刷新）

## 顺带说：步骤 3 的"框"画在哪

就在 `FitAndDraw()` 的最后那一步之后 —— **先 `DispObj` 图像，再叠框和编号**。
现在方法里已经留了这行注释，到时候只加几行，别的地方不用动。

## 4.1 `ViewModel/MainViewModel.cs`（整文件替换，★ 是新增）

> 🏛 **类 `MainViewModel`** ｜ 只加"读图"，不碰显示

```csharp
using System.IO;
using System.Windows.Threading;
using CommunityToolkit.Mvvm.ComponentModel;
using CommunityToolkit.Mvvm.Input;
using HalconDotNet;                          // ★ 步骤2：HImage / HOperatorSet
using Serilog;

namespace HelcWPF
{
    public partial class MainViewModel : ObservableObject, IDisposable
    {
        #region 字段
        private readonly ImageSourceService _source;
        private readonly ILogger _log = Log.ForContext<MainViewModel>();
        private readonly DispatcherTimer _autoTimer;
        #endregion

        #region 属性
        [ObservableProperty] private string _statusText = "请先选择数据源文件夹";
        [ObservableProperty] private string _folderPath = "未选择文件夹";
        [ObservableProperty] private string _currentFileName = "-";
        [ObservableProperty] private string _progressText = "0/0";

        // ★ 步骤2 新增：状态栏显示"1440×1080  3 通道"
        [ObservableProperty] private string _imageInfoText = "-";

        [ObservableProperty] private int _autoIntervalMs = 1000;
        [ObservableProperty] private bool _isAutoMode = false;

        /// <summary>★ 步骤2 新增：当前图像对象。View 监听它变化 → 显示到 HALCON 控件</summary>
        [ObservableProperty] private HImage? _currentImage;
        #endregion

        public MainViewModel(ImageSourceService source)
        {
            _source = source;
            _autoTimer = new DispatcherTimer { Interval = TimeSpan.FromMilliseconds(AutoIntervalMs) };
            _autoTimer.Tick += OnAutoTimerTick;
        }

        #region RelayCommand
        [RelayCommand]
        private void SelectFolder()
        {
            var dialog = new Microsoft.Win32.OpenFolderDialog
            {
                Title = "选择数据源文件夹",
                InitialDirectory = Directory.Exists(ImageSourceService.DefaultFolder)
                    ? ImageSourceService.DefaultFolder
                    : AppContext.BaseDirectory
            };

            if (dialog.ShowDialog() != true) return;

            int count = LoadFolder(dialog.FolderName);
            StatusText = count > 0 ? $"已加载 {count} 张图片" : "这个文件夹里没有支持的图片";
        }

        [RelayCommand(CanExecute = nameof(CanNavigate))]
        private void Next() => Navigate(+1);

        [RelayCommand(CanExecute = nameof(CanNavigate))]
        private void Previous() => Navigate(-1);

        private bool CanNavigate() => _source.HasImages;
        #endregion

        #region 业务逻辑
        public int LoadFolder(string folder)
        {
            bool wasAuto = IsAutoMode;
            StopAuto(updateStatus: false);

            int count = _source.LoadFolder(folder);
            FolderPath = count > 0 ? folder : $"{folder}（没有图片）";

            if (count > 0)
            {
                ShowCurrent();
            }
            else
            {
                CurrentImage?.Dispose();                    // ★ 步骤2：清掉上一批的图
                CurrentImage = null;
                CurrentFileName = "-";
                ProgressText = "0/0";
                ImageInfoText = "-";
            }

            RefreshNavigation();

            if (wasAuto && count > 0) StartAuto();
            return count;
        }

        private void Navigate(int step)
        {
            if (IsAutoMode) IsAutoMode = false;             // 自动播放时点上下页 → 先切回手动

            bool moved = step > 0 ? _source.MoveNext() : _source.MovePrevious();

            if (!moved)
            {
                string bound = step > 0 ? "最后一张" : "第一张";
                StatusText = $"已经是{bound}了";
                _log.Information("[切换] 已到边界（{Bound}），当前 {Index}/{Total}",
                    bound, _source.CurrentIndex + 1, _source.Count);
                return;
            }

            ShowCurrent();
        }

        /// <summary>★ 状态更新的唯一出口：翻页 / 自动播放 / 换文件夹最后都走这里</summary>
        private void ShowCurrent()
        {
            var item = _source.Current;
            if (item is null) return;

            CurrentFileName = item.FileName;
            ProgressText = $"{_source.CurrentIndex + 1} / {_source.Count}";
            LoadImage(item);                                // ★ 步骤2 新增：读图
            RefreshNavigation();

            _log.Information("[切换] {Mode} 第 {Index}/{Total} 张 → {File}",
                IsAutoMode ? "自动" : "手动", item.Index, _source.Count, item.FileName);
        }

        /// <summary>
        /// ★ 步骤2 新增：把当前这张读进内存。
        /// 读图算业务（换别的显示方式也照样要读）→ 放 VM；显示才是 View 的事。
        /// </summary>
        private void LoadImage(ImageItem item)
        {
            CurrentImage?.Dispose();                        // 释放上一张（HALCON 对象是 native 资源）
            CurrentImage = null;

            try
            {
                var image = new HImage(item.FilePath);       // = HDevelop 的 read_image

                HOperatorSet.GetImageSize(image, out HTuple width, out HTuple height);
                HOperatorSet.CountChannels(image, out HTuple channels);

                CurrentImage = image;                        // ★ 赋值 → 触发 View 去显示
                ImageInfoText = $"{width.I}×{height.I}  {channels.I} 通道";
                _log.Information("[图像] 读入 {File}：{W}×{H}，{C} 通道",
                    item.FileName, width.I, height.I, channels.I);
            }
            catch (HalconException ex)                       // 损坏图片、没权限…都走这
            {
                ImageInfoText = "-";
                StatusText = "读图失败：" + ex.Message;
                _log.Error(ex, "[图像] 读图失败：{Path}", item.FilePath);
            }
        }

        private void RefreshNavigation()
        {
            NextCommand.NotifyCanExecuteChanged();
            PreviousCommand.NotifyCanExecuteChanged();
        }

        private void OnAutoTimerTick(object? sender, EventArgs e)
        {
            if (!_source.MoveNext())
            {
                IsAutoMode = false;
                StatusText = "已到最后一张，自动切换结束";
                _log.Information("[播放] 已到最后一张，自动切换结束");
                return;
            }
            ShowCurrent();
        }

        private void StartAuto()
        {
            int interval = Math.Max(50, AutoIntervalMs);
            _autoTimer.Interval = TimeSpan.FromMilliseconds(interval);
            _autoTimer.Start();
            StatusText = $"自动切换中（间隔 {interval} ms）";
            _log.Information("[播放] 开始自动切换，间隔 {Interval} ms", interval);
        }

        private void StopAuto(bool updateStatus = true)
        {
            if (_autoTimer.IsEnabled)
            {
                _autoTimer.Stop();
                _log.Information("[播放] 停止自动切换");
            }
            if (updateStatus) StatusText = "手动模式：用「上一页 / 下一页」翻页";
        }

        #region 属性变化钩子
        partial void OnIsAutoModeChanged(bool value)
        {
            if (value)
            {
                if (!_source.HasImages)
                {
                    StatusText = "请先选择数据源文件夹";
                    _log.Warning("[播放] 未加载图片，无法开始自动切换");
                    IsAutoMode = false;
                    return;
                }
                StartAuto();
            }
            else
            {
                StopAuto();
            }
        }

        partial void OnAutoIntervalMsChanged(int value)
        {
            if (value > 0 && _autoTimer is not null)
            {
                _autoTimer.Interval = TimeSpan.FromMilliseconds(value);
                _log.Information("[播放] 切换间隔改为 {Interval} ms", value);
            }
        }
        #endregion

        public void Dispose()
        {
            _autoTimer.Stop();
            _autoTimer.Tick -= OnAutoTimerTick;
            CurrentImage?.Dispose();                        // ★ 步骤2：关窗口时释放图像
            CurrentImage = null;
        }
        #endregion
    }
}
```

## 4.3 `Views/MainWindow.xaml.cs`（整文件替换）

```csharp
// ============================================================================
//  Views/MainWindow.xaml.cs —— 窗口自身行为 + 把图像显示到 HALCON 大屏
//
//  显示就三行： SetPart(按比例算好的显示区域) + ClearWindow + DispObj
//  比例为什么不能交给控件：控件的 HKeepAspectRatio 只在"控件尺寸变化时"生效，
//  初次显示和手动 disp 时它不管 → 图会被拉满窗口（实测会被拉伸到 1.88/2.20 的比例）。
//
//  画图必须等 HInitWindow（HALCON 窗口句柄就绪），否则报 #2453 HALCON handle is NULL。
// ============================================================================

using System.ComponentModel;
using System.Windows;
using System.Windows.Input;
using HalconDotNet;
using Serilog;

namespace HelcWPF;

public partial class MainWindow : Window
{
    private readonly ILogger _log = Log.ForContext<MainWindow>();
    private readonly MainViewModel _viewModel;

    private bool _halconReady;      // HInitWindow 之后才为 true
    private HImage? _shown;         // 已经显示过的图像（同一张不重复画）

    public MainWindow(MainViewModel viewModel)
    {
        InitializeComponent();

        _viewModel = viewModel;
        DataContext = viewModel;          // ★ 绑定总开关

        // ① ViewModel 的"当前图像"变了 → 由 View 负责显示
        _viewModel.PropertyChanged += OnViewModelPropertyChanged;

        // ② 等 HALCON 窗口初始化完成（句柄就绪）才能画图
        HalconView.HInitWindow += (_, _) =>
        {
            _halconReady = true;
            _log.Information("[图像] HALCON 窗口初始化完成（句柄已可用）");
            ShowCurrentImage();           // 可能 ViewModel 早就准备好了图，这里补显示
        };

        // ③ 窗口大小变了 → 重新按比例适应（比例是我们自己算的，所以要重算）
        HalconView.SizeChanged += (_, _) =>
        {
            if (_halconReady && _viewModel.CurrentImage is not null) FitAndDraw();
        };
    }

    #region 显示图像

    private void OnViewModelPropertyChanged(object? sender, PropertyChangedEventArgs e)
    {
        if (e.PropertyName == nameof(MainViewModel.CurrentImage))
            ShowCurrentImage();
    }

    private void ShowCurrentImage()
    {
        if (!_halconReady) return;                     // 句柄没好，等 HInitWindow

        var image = _viewModel.CurrentImage;
        if (image is null || ReferenceEquals(image, _shown)) return;

        _shown = image;
        FitAndDraw();
    }

    /// <summary>
    /// 把整幅图按比例显示到窗口：
    ///   part 的宽高比 = 窗口宽高比，且刚好包住图像
    ///   → 短的那边落在图像外，显示成窗口背景（黑边），图像本身不变形
    /// </summary>
    private void FitAndDraw()
    {
        var image = _viewModel.CurrentImage;
        if (image is null || !_halconReady) return;

        HalconView.HalconWindow.GetWindowExtents(out int _, out int _, out int winW, out int winH);
        if (winW <= 0 || winH <= 0) return;

        HOperatorSet.GetImageSize(image, out HTuple w, out HTuple h);
        double imgW = w.D, imgH = h.D;

        double winAspect = (double)winW / winH;
        double partW, partH;
        if (imgW / imgH > winAspect)      // 图比窗口"宽" → 上下留黑边
        {
            partW = imgW;
            partH = imgW / winAspect;
        }
        else                              // 图比窗口"高" → 左右留黑边
        {
            partH = imgH;
            partW = imgH * winAspect;
        }

        double row1 = imgH / 2 - partH / 2;
        double col1 = imgW / 2 - partW / 2;

        try
        {
            HWindow window = HalconView.HalconWindow;
            window.SetPart(row1, col1, row1 + partH, col1 + partW);   // 显示区域
            window.ClearWindow();
            window.DispObj(image);                                   // 画图像
            // ★ 步骤3 的检测框加在这里：先 DispObj 图像，再叠框 / 编号
        }
        catch (HalconException ex)
        {
            _log.Error(ex, "[图像] 显示失败");
            _viewModel.StatusText = "显示失败：" + ex.Message;
        }
    }

    #endregion

    #region 标题栏 / 窗口按钮

    private void TitleBar_MouseLeftButtonDown(object sender, MouseButtonEventArgs e)
    {
        if (e.ClickCount == 2)
        {
            ToggleMaximize();
            return;
        }

        try { DragMove(); }
        catch (InvalidOperationException) { }
    }

    private void Minimize_Click(object sender, RoutedEventArgs e)
        => WindowState = WindowState.Minimized;

    private void Maximize_Click(object sender, RoutedEventArgs e)
        => ToggleMaximize();

    private void Close_Click(object sender, RoutedEventArgs e)
        => Close();

    private void ToggleMaximize()
        => WindowState = WindowState == WindowState.Maximized ? WindowState.Normal : WindowState.Maximized;

    // WindowChrome 自绘标题栏时，最大化会往外溢 8 像素（系统的隐形边框），用工作区尺寸压回来
    protected override void OnStateChanged(EventArgs e)
    {
        base.OnStateChanged(e);

        if (WindowState == WindowState.Maximized)
        {
            MaxHeight = SystemParameters.WorkArea.Height + 8;
            MaxWidth = SystemParameters.WorkArea.Width + 8;
        }
        else
        {
            MaxHeight = double.PositiveInfinity;
            MaxWidth = double.PositiveInfinity;
        }
    }

    #endregion

    protected override void OnClosed(EventArgs e)
    {
        _viewModel.PropertyChanged -= OnViewModelPropertyChanged;   // 解绑
        _viewModel.Dispose();                                       // 释放图像 + 停定时器
        base.OnClosed(e);
    }
}
```

| 现象 | 原因 | 解决 |
|---|---|---|
| XAML 报"找不到类型 HSmartWindowControlWPF" | Window 标签少了 `xmlns:halcon` | 加 `xmlns:halcon="clr-namespace:HalconDotNet;assembly=halcondotnet"` |

| 最大化后变形 | 尺寸变化没重算 | `HalconView.SizeChanged` → `FitAndDraw()` |
| 运行报 `#2453 HALCON handle is NULL` | 在控件构造/`Loaded` 里就画图 | 画图放 `HInitWindow` 里（本页已处理） |
| 换了图但屏幕还是旧的 | View 没订阅 `CurrentImage` 变化 | 构造函数里 `_viewModel.PropertyChanged += …` |
| 内存一直涨 | `HImage` 没 Dispose | 三个点：换图前、清空文件夹时、`Dispose()` 里（本页都有） |
| 关窗后日志报对象还在 | 事件没解绑 | `OnClosed` 里 `-=` 再 `Dispose` |

# 7. 面试怎么说

> **图像怎么显示到界面上的？**
> HALCON 显示的本质是 `set_part`（决定显示图像上的哪一块）+ `disp_obj`（画出来）。ViewModel 负责读图（`new HImage` 相当于 read_image），把图像暴露成一个可观察属性；View 监听这个属性，在 `HInitWindow`（HALCON 窗口句柄就绪事件）之后调用显示方法。注意不能在控件构造或 `Loaded` 里画，那时句柄还是空的，会报 `#2453 HALCON handle is NULL`。
>
> **怎么保证图像不变形？**
> 图像坐标和窗口坐标是两套坐标系，不变形的条件是 **part 的宽高比等于窗口宽高比**。我一开始想省事用控件自带的 `SetFullImagePart` + `HKeepAspectRatio`，实测发现它只在"控件尺寸变化时"才生效，初次显示和手动 disp 会把图拉满窗口（量出来比例 1.88，原图是 1.33）。所以改成自己算 part：让 part 刚好包住图像、宽高比对齐窗口，多出来的部分落在图像外自然形成黑边；窗口尺寸变化时重算一次。
>
> **为什么不加缩放拖动？**
> 现在的需求只是"看清楚这张图和检测框"，缩放拖动不是必须的。控件自带的那套交互是"缩放窗口像素"的思路，之前还出现过"缩放后图片消失、只剩标记"的问题，所以我先不引入，等确实需要时再自己用 part 实现（那时只需要在鼠标事件里改 part 再重画，我已经验证过这条路可行）。
