| 文件 | 里面的类 | 这个类负责 |

| `Models/ImageItem.cs` | 类 `ImageItem` | 描述"一张图片"：路径、序号、文件名 |

| `App.xaml.cs` | 类 `App` | 组装三层 |

**判据：看这段代码"碰了什么"**

| 代码里出现了… | 属于 | 放错的后果 |
|---|---|---|
| `Directory` / `File` / `Path` / 排序 / 游标下标 | 类 `ImageSourceService` | 塞进 ViewModel → 以后换数据源要改两处，没法脱离界面测 |
| `MessageBox` / `Application` / `Dispatcher` / 控件类型 | **不许进 Service** | 写进去 → 这个类再也不能用控制台单独跑 |
| 绑定属性（`FolderPath`…）/ 命令 / 定时器 | 类 `MainWindowViewModel` | 写进 code-behind → 越写越乱、没法测 |
| XAML 控件 / `{Binding}` / `Click` | 类 `MainWindow`（.xaml） | 写成 `TxtXxx.Text = ...` → 界面和状态耦合 |
| 只有字段属性、没有行为 | 类 `ImageItem` | 往里塞读文件/排序 → 数据和规则混一起 |

三句口诀：**Service 里不许出现 WPF 类型；ViewModel 里不许出现控件类型；ViewModel 里不许直接读写文件（要问 Service）。**

# 2. 五个功能的思路（先看懂再敲）

## 功能① 选文件夹的思路

1. 界面放个按钮，**不写 `Click`**，写 `Command="{Binding SelectFolderCommand}"`（命令模式，以后能自动置灰）。
2. 命令里弹系统文件夹框：`Microsoft.Win32.OpenFolderDialog`（.NET 8 的 WPF 原生，别用 WinForms 那个）。
3. 拿到路径 → 交给 `ImageSourceService.LoadFolder()` 扫描：
   **按扩展名过滤**（`jpg/jpeg/png/bmp/tif/tiff`）→ **跳过隐藏文件** → **排序**（功能②）。
4. 扫描完**把游标复位到第 1 张**（换了文件夹，旧游标就失效了）。
5. **返回图片数量**，界面据此提示（0 张 → "没有支持的图片"）。

## 功能② 自然排序的思路

1. 问题：字符串默认**逐字符**比 → `"1" < "10" < "100" < "2"`，顺序会变成 `1,10,100,101…`。
2. 目标：把文件名里的**连续数字段按数值比**，其它字符按字符比 → `1,2,3,…,10,…,100`。
3. 算法（逐字符扫描）：
   - 两边当前都是数字 → 把**整段数字**取出来：**去前导零** → **先比位数** → 位数相同再比字典序 → 相等就继续往后比；
   - 否则按字符比（忽略大小写）。
4. 收尾：一个是另一个的前缀时，短的排前面。
5. 写成**独立比较器类**：能单独测、以后能换规则、别处能复用。

## 功能③ 切换（上一页/下一页）的思路

1. Service 里只维护一个**游标**（当前下标），不存"当前图片对象"。
2. 移动 = 改游标，但先判边界：`CanMoveNext`（下标 < 总数-1）、`CanMovePrevious`（下标 > 0）——**边界规则放 Service**。
3. `MoveNext()` / `MovePrevious()` **返回 bool**：到尽头返回 `false`（这是正常状态，不抛异常）。
4. 移动成功后走**同一个刷新方法** `ShowCurrent()`：取当前项 → 写绑定属性 → 刷新按钮状态 → 记日志。**刷新只有这一个出口**。
5. **按钮可用性**：`CanNavigate` 只判断"有没有加载图片"（`_source.HasImages`）。
   即**只要有图片，上一页/下一页就一直可点**；点到边界不置灰，只提示"已经是最后一张了"——比按钮忽明忽暗好用。
6. **点上下页时如果正在自动播放 → 先切回手动**（`IsAutoMode = false` 自动停表）再翻页，方便随时"停下来看这一张"。

## 功能④ 自动切换的思路（★ 按你的要求改过）

1. 用 `DispatcherTimer` 做节拍器（回调在 **UI 线程**，能直接改绑定属性；`System.Timers.Timer` 会跨线程异常）。
2. **开关直接控制播放，不再需要"开始/停止"按钮**：
   - 勾上「自动切换」→ 立刻按间隔开始翻页；
   - 取消勾选 → 立刻停表。
   实现：写在**属性变化钩子** `partial void OnIsAutoModeChanged(bool value)` 里。
   ⚠️ 名字必须跟属性严格对上（`On` + 属性名 + `Changed`，而且必须 `partial void`），否则**永远不会被调用**——这是这次踩到的坑。
3. 每次滴答 = 翻一张（复用功能③的 `MoveNext()` + `ShowCurrent()`）。
4. 三种停止：到末尾自动停 / 取消勾选开关 / 点上下页自动转手动。
5. 还没选文件夹就勾开关 → 提示"请先选择数据源文件夹"，并把开关**弹回去**（不能显示"自动中"却什么都没发生）。
6. 间隔输入框改了就**立刻生效**（`OnAutoIntervalMsChanged` 里更新节拍器，播放中途改也行）。

## 功能⑤ 状态显示的思路

1. 所有文字**只走绑定**，代码里一次都不写 `TxtXxx.Text = ...`。
2. 要显示的 4 个字符串声明成 `[ObservableProperty]` 字段（`FolderPath` / `CurrentFileName` / `ProgressText` / `StatusText`）。
3. 谁写它们：`LoadFolder` 写 `FolderPath`/`StatusText`；`ShowCurrent` 写 `CurrentFileName`/`ProgressText`；`Start`/`Stop`/`OnAutoTimerTick` 写 `StatusText`。

## 4.2 `Services/ImageSourceService.cs` —— 新建，整段贴

> 🏛 **两个类都在这个文件里**：`ImageSourceService`（扫盘/排序/游标）和 `NaturalStringComparer`（比较器，`internal`，界面看不到）
>
> ⚠️ 这个文件里**不许出现任何 WPF 类型**。

```csharp
using System.IO;
using Serilog;

namespace HelcWPF;

/// <summary>
/// 数据源：扫描文件夹 + 自然排序 + 翻页游标。
/// 不引用任何 WPF 类型、也不发通知 —— 只是被动的数据源，问了才答。
/// </summary>
public sealed class ImageSourceService
{
    /// <summary>默认数据源文件夹（步骤 9 会挪进配置文件）</summary>
    public const string DefaultFolder = @"D:\PictureForMvt\508Pic";

    /// <summary>认得的图片扩展名</summary>
    public static readonly string[] SupportedExtensions =
        { ".jpg", ".jpeg", ".png", ".bmp", ".tif", ".tiff" };

    private readonly ILogger _log = Log.ForContext<ImageSourceService>();
    private readonly List<ImageItem> _images = new();

    public IReadOnlyList<ImageItem> Images => _images;
    public string FolderPath { get; private set; } = string.Empty;
    public int CurrentIndex { get; private set; } = -1;      // 只有本类能改
    public int Count => _images.Count;

    /// <summary>当前这张；没有就 null（比返回 -1 安全）</summary>
    public ImageItem? Current =>
        CurrentIndex >= 0 && CurrentIndex < _images.Count ? _images[CurrentIndex] : null;

    /// <summary>边界判断收在数据层，界面/VM 不用自己算</summary>
    public bool CanMoveNext => CurrentIndex >= 0 && CurrentIndex < _images.Count - 1;
    public bool CanMovePrevious => CurrentIndex > 0;

    /// <summary>
    /// 扫描文件夹：清空 → 过滤 → 排序 → 建列表 → 游标复位到第 1 张。
    /// 返回图片数量，调用方据此判断"有没有图"。
    /// </summary>
    public int LoadFolder(string folder)
    {
        _images.Clear();
        CurrentIndex = -1;                                   // ★ 先复位，避免指向旧位置
        FolderPath = folder;

        if (!Directory.Exists(folder))
        {
            _log.Warning("数据源文件夹不存在：{Folder}", folder);
            return 0;
        }

        var files = Directory.EnumerateFiles(folder)
            .Where(f => SupportedExtensions.Contains(Path.GetExtension(f), StringComparer.OrdinalIgnoreCase))
            .Where(f => (File.GetAttributes(f) & FileAttributes.Hidden) == 0)
            .ToList();

        files.Sort(NaturalStringComparer.Instance);          // ★ 自然排序，见文件末尾那个类

        for (int i = 0; i < files.Count; i++)
            _images.Add(new ImageItem(files[i], i + 1));     // 序号从 1 开始

        if (_images.Count > 0) CurrentIndex = 0;             // 有图 → 停在第 1 张

        // 日志打前 10 张：排序对不对一眼可见
        _log.Information("加载数据源 {Folder}：{Count} 张，首张={First}，前 10 张：{Names}",
            folder, _images.Count, Current?.FileName ?? "(无)",
            string.Join(", ", _images.Take(10).Select(x => x.FileName)));

        return _images.Count;
    }

    /// <summary>下一张。返回"是否真的移动了" —— 到尽头是正常状态，不抛异常</summary>
    public bool MoveNext()
    {
        if (!CanMoveNext) return false;
        CurrentIndex++;
        return true;
    }

    public bool MovePrevious()
    {
        if (!CanMovePrevious) return false;
        CurrentIndex--;
        return true;
    }
}

// ============================================================================
//  自然排序比较器（独立的一个类，只是跟上面写在同一个文件里）
//  1.jpg < 2.jpg < 10.jpg < 100.jpg   （字典序会排成 1, 10, 100, 2）
// ============================================================================
internal sealed class NaturalStringComparer : IComparer<string>
{
    public static readonly NaturalStringComparer Instance = new();   // 无状态，单例即可

    public int Compare(string? x, string? y)
    {
        if (ReferenceEquals(x, y)) return 0;
        if (x is null) return -1;
        if (y is null) return 1;

        int i = 0, j = 0;
        while (i < x.Length && j < y.Length)
        {
            if (char.IsDigit(x[i]) && char.IsDigit(y[j]))
            {
                // 两边都走到数字段：整段取出来，按数值比
                int startI = i, startJ = j;
                while (i < x.Length && char.IsDigit(x[i])) i++;
                while (j < y.Length && char.IsDigit(y[j])) j++;

                string numX = x.Substring(startI, i - startI).TrimStart('0');   // "007" == "7"
                string numY = y.Substring(startJ, j - startJ).TrimStart('0');

                if (numX.Length != numY.Length) return numX.Length - numY.Length;  // 位数多的数值大
                int cmp = string.CompareOrdinal(numX, numY);
                if (cmp != 0) return cmp;
                // 数值相等 → 继续往后比
            }
            else
            {
                int cmp = char.ToUpperInvariant(x[i]).CompareTo(char.ToUpperInvariant(y[j]));
                if (cmp != 0) return cmp;
                i++; j++;
            }
        }
        return (x.Length - i) - (y.Length - j);      // 前缀相同：短的在前
    }
}
```

## 4.3 `ViewModels/MainWindowViewModel.cs` —— 新建，整段贴

> 🏛 **类 `MainWindowViewModel`**（⚠️ 不许出现控件类型；不许直接读写文件）

```csharp
using System.Windows.Threading;
using CommunityToolkit.Mvvm.ComponentModel;
using CommunityToolkit.Mvvm.Input;
using Serilog;

namespace HelcWPF;

/// <summary>
/// 主界面的"大脑"：界面要显示的状态 + 用户每个操作对应的命令。
/// </summary>
public partial class MainWindowViewModel : ObservableObject, IDisposable
{
    private readonly ImageSourceService _source;
    private readonly DispatcherTimer _autoTimer;
    private readonly ILogger _log = Log.ForContext<MainWindowViewModel>();

    // ─────────────── 界面绑定的状态（[ObservableProperty] 编译期生成属性+通知）───────────────

    [ObservableProperty] private string _folderPath = "(未选择文件夹)";       // 工具条右侧
    [ObservableProperty] private string _currentFileName = "-";               // 状态栏左侧
    [ObservableProperty] private string _progressText = "0 / 0";              // 状态栏右侧
    [ObservableProperty] private string _statusText = "请先选择数据源文件夹";  // 状态栏中间
    [ObservableProperty] private int _autoIntervalMs = 300;                   // 自动播放间隔
    [ObservableProperty] private bool _isAutoMode = true;                     // 自动/手动开关

    /// <summary>是否正在播放；它一变，开始/停止按钮的可用状态自动刷新</summary>
    [ObservableProperty]
    [NotifyCanExecuteChangedFor(nameof(StartCommand))]
    [NotifyCanExecuteChangedFor(nameof(StopCommand))]
    private bool _isPlaying;

    // ─────────────── 构造 ───────────────

    public MainWindowViewModel(ImageSourceService source)     // ★ 构造注入 Service，不自己 new
    {
        _source = source;

        // DispatcherTimer：回调在 UI 线程，可直接改绑定属性（System.Timers.Timer 会跨线程异常）
        _autoTimer = new DispatcherTimer { Interval = TimeSpan.FromMilliseconds(AutoIntervalMs) };
        _autoTimer.Tick += OnAutoTimerTick;
    }

    // ─────────────── 命令（界面上每个按钮对应一个；XAML 里不写 Click）───────────────

    [RelayCommand]
    private void SelectFolder()
    {
        var dialog = new Microsoft.Win32.OpenFolderDialog
        {
            Title = "选择数据源文件夹",
            InitialDirectory = System.IO.Directory.Exists(ImageSourceService.DefaultFolder)
                ? ImageSourceService.DefaultFolder
                : AppContext.BaseDirectory
        };

        if (dialog.ShowDialog() != true) return;              // 用户取消

        int count = LoadFolder(dialog.FolderName);
        StatusText = count > 0
            ? $"已加载 {count} 张图片"
            : "这个文件夹里没有支持的图片（jpg/jpeg/png/bmp/tif/tiff）";
    }

    [RelayCommand(CanExecute = nameof(CanNext))]
    private void Next()
    {
        if (_source.MoveNext()) ShowCurrent();                // 移动成功才刷新
    }
    private bool CanNext() => _source.CanMoveNext;            // 转问 Service，不自己算下标

    [RelayCommand(CanExecute = nameof(CanPrevious))]
    private void Previous()
    {
        if (_source.MovePrevious()) ShowCurrent();
    }
    private bool CanPrevious() => _source.CanMovePrevious;

    [RelayCommand(CanExecute = nameof(CanStart))]
    private void Start()
    {
        if (_source.Count == 0) { StatusText = "还没有图片，请先选择数据源文件夹"; return; }

        IsPlaying = true;                                     // → 开始变灰、停止点亮

        if (IsAutoMode)
        {
            _autoTimer.Interval = TimeSpan.FromMilliseconds(Math.Max(50, AutoIntervalMs));
            _autoTimer.Start();
            StatusText = $"自动播放中（间隔 {AutoIntervalMs} ms）";
        }
        else
        {
            ShowCurrent();
            StatusText = "手动模式：用「上一张 / 下一张」翻页";
        }
    }
    private bool CanStart() => !IsPlaying;

    [RelayCommand(CanExecute = nameof(CanStop))]
    private void Stop()
    {
        _autoTimer.Stop();
        IsPlaying = false;
        StatusText = "已停止";
    }
    private bool CanStop() => IsPlaying;

    // ─────────────── 内部逻辑 ───────────────

    /// <summary>public：命令行/自检等非界面入口也能用（步骤 3 会用到）</summary>
    public int LoadFolder(string folder)
    {
        Stop();                                               // 换数据源前先停播
        int count = _source.LoadFolder(folder);
        FolderPath = count > 0 ? folder : $"{folder}（没有图片）";

        if (count > 0) ShowCurrent();
        else { CurrentFileName = "-"; ProgressText = "0 / 0"; }

        RefreshNavigation();
        return count;
    }

    /// <summary>
    /// ★ 把"数据源当前这张"变成"界面状态"。
    /// 手动翻页、自动播放、换文件夹最后都汇到这里 —— 状态更新只有这一个出口。
    /// 步骤 2 加图像显示只需改这一个方法。
    /// </summary>
    private void ShowCurrent()
    {
        var item = _source.Current;                           // ① 向 Service 要数据
        if (item is null) return;                             // ② 兜底

        CurrentFileName = item.FileName;                      // ③ 写属性 → 界面自动刷新
        ProgressText = $"{_source.CurrentIndex + 1} / {_source.Count}";
        RefreshNavigation();                                  // ④ 边界可能变了 → 让按钮重新求值
        _log.Information("当前第 {Index}/{Total} 张：{File}", // ⑤ 留证据（无人值守验证用）
            item.Index, _source.Count, item.FileName);
    }

    /// <summary>游标不是可观察属性，WPF 不知道它变了 → 必须手动让命令重新求值</summary>
    private void RefreshNavigation()
    {
        PreviousCommand.NotifyCanExecuteChanged();
        NextCommand.NotifyCanExecuteChanged();
    }

    private void OnAutoTimerTick(object? sender, EventArgs e)
    {
        if (!_source.MoveNext()) { Stop(); StatusText = "已到最后一张，自动播放结束"; return; }
        ShowCurrent();
    }

    // ─────────────── 属性变化钩子（名字由源生成器规定，不能改）───────────────

    partial void OnAutoIntervalMsChanged(int value)           // 界面上改了间隔 → 节拍器立刻跟着改
    {
        if (value > 0) _autoTimer.Interval = TimeSpan.FromMilliseconds(value);
    }

    partial void OnIsAutoModeChanged(bool value)              // 播放中切回手动 → 自动停
    {
        if (!value && _autoTimer.IsEnabled)
        {
            _autoTimer.Stop();
            StatusText = "已切到手动模式：用「上一张 / 下一张」翻页";
        }
    }

    public void Dispose()
    {
        _autoTimer.Stop();
        _autoTimer.Tick -= OnAutoTimerTick;                   // 解绑，避免窗口关了定时器还在跑
    }
}
```

# 7. 常见坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 编译报"找不到 `SelectFolderCommand`" | 类没写 `partial`，或方法没标 `[RelayCommand]` | 类声明 `public partial class`，方法上加 `[RelayCommand]` |
| 点按钮没反应 | 忘设 `DataContext` | 构造函数里 `DataContext = viewModel;` |
| 按钮一直灰 | `CanExecute` 返回 false / 命令名写错 | `CanNext` 用 `_source.CanMoveNext`；命名 `Next`→`NextCommand` |
| 界面不刷新 | 普通字段 | 字段标 `[ObservableProperty]` |
| 翻页后按钮不置灰 | 忘通知 | `ShowCurrent()` 里调 `RefreshNavigation()` |
| 排序是 1,10,100 | 没调用比较器 | `files.Sort(NaturalStringComparer.Instance);` |
| 目录对话框打不开 | 用了 WinForms 的 `FolderBrowserDialog` | 用 `Microsoft.Win32.OpenFolderDialog` |
| 间隔框改了不管用 | 少了 `UpdateSourceTrigger=PropertyChanged` | 加上 |
| 编译报 `Application` 不明确 | 项目同时开 WPF/WinForms | csproj 里已有 `<Using Remove="System.Windows.Forms" />`，别删 |
| 关窗后定时器还在跑 | 没释放 | `OnClosed` 里 `_viewModel.Dispose()` |

# 8. 面试怎么说（按功能讲）

> **选文件夹**：按钮绑 `RelayCommand`，命令里用 `Microsoft.Win32.OpenFolderDialog` 拿路径，扫描交给 `ImageSourceService`：按扩展名过滤、跳过隐藏文件、自然排序、游标复位，返回数量让界面提示"空文件夹"。扫描不写在 ViewModel 里，因为它跟界面无关，放 Service 才能脱离界面用控制台验证。
>
> **排序**：默认字符串比较是逐字符的，会出现 1、10、100、2。我写了自然排序比较器：遇到连续数字段整段取出来按数值比 —— 去前导零、比位数、位数相同再按字符比，相等就继续往后比。
>
> **切换**：Service 维护游标，`CanMoveNext/CanMovePrevious` 做边界判断，`MoveNext()` 返回 bool（到尽头是正常状态不是异常）。命令的 `CanExecute` 直接转问 Service，按钮就自动置灰；翻页成功后统一走 `ShowCurrent()` 刷新界面，这是状态更新的唯一出口，将来加图像显示只改它一处。游标不是可观察属性，所以翻页后手动 `NotifyCanExecuteChanged`。
>
> **自动切换**：`DispatcherTimer`，回调在 UI 线程能直接更新绑定属性（`System.Timers.Timer` 会跨线程异常）。每次滴答翻一张，到末尾自动停；`IsPlaying` 用 `[NotifyCanExecuteChangedFor]` 驱动开始/停止按钮的可用状态。
