# 2. 先看数据（这一步最重要的部分）

我看不见图，所以**先用标注把"零件长什么样"量出来**（`train.txt`：410 张图，1493 个螺丝 + 1440 个螺母）。
做法：在每个标注框里做一次二值化，取最大的那块，量形状 —— 40 张图、166 个螺丝、117 个螺母：

| 特征 | 螺丝（bolt） | 螺母（nut） | 结论 |
|---|---|---|---|
| **拟合矩形长宽比** | 中位 **2.40**（10%:1.46 / 90%:2.87） | 中位 **1.07**（1.01~1.14） | ⭐ 分得很开 → 主要特征 |
| **圆度** | 中位 **0.26** | 中位 **0.78** | ⭐ 分得很开 → 备用特征 |
| 面积（像素） | 16388（11594~22930） | 8396（4805~11789） | 有重叠，**不能只靠面积分类** |
| 标注框尺寸 | 220×259 | 136×142 | 螺母尺寸很统一 |

**两条结论**：
1. **螺丝是平躺的细长件**（长宽比 2.4、圆度 0.26），**螺母接近方圆**（长宽比 1.07、圆度 0.78）→ 分类用长宽比就行，阈值取 1.5 / 1.3。
2. 零件**比背景暗**（白盘子上）→ 二值化用 `dark` 极性；这也印证了你说的"白色盘子背景"。

## 分割参数是"扫"出来的，不是拍脑袋定的

同样 40 张图，用严格 IoU 评估，扫了一遍参数（节选）：

| 阈值 | 闭运算半径 | 精确率 P | 召回率 R | F1 | 分类准确率 | 连通域个数 |
|---|---|---|---|---|---|---|
| **自动（max_separability）** | 0 | 0.284 | 0.258 | **0.270** | 94.5% | 386 |
| 100 | 6 | 0.787 | 0.678 | 0.729 | 97.9% | 30 |
| 110 | 5 | 0.834 | 0.693 | 0.757 | 96.9% | — |
| **120** | **5** | **0.887** | **0.724** | **0.798** | **96.6%** | — |
| 130 | 5 | 0.890 | 0.686 | 0.774 | 97.4% | — |
| 140 | 0 | 0.838 | 0.622 | 0.714 | 97.2% | 227 |
| 160 | — | 0.400 | 0.014 | 0.027 | — | 25 |

**两个反直觉的发现**（都是数据说的）：
1. **HALCON 的自动阈值（`binary_threshold('max_separability')`）在这批图上很差**：F1 只有 0.27。
   原因：它按直方图找"最优分界"，切出来的是零件最暗的**边缘/阴影**，金属高光的部分被漏掉 → 零件被切成碎片（1.jpg 里有 386 个连通域！）。
   → 改成**手动阈值 120**（背景约 150，零件约 60~120），F1 从 0.27 涨到 0.79。
2. **闭运算（`closing_circle`）在这里是"救命的"**：半径 5 能把被高光切断的碎片连回一个零件。
   但半径不能太大（6 以上会把相邻零件粘成一块，召回率反而掉）→ 5 是这批图上的最优点。

**还差什么（诚实说明）**：召回率 0.724 → **约 1/4 的零件没框到**。主要原因是：
- 相邻零件被闭运算粘成一个（一个区域对上两个标注 → 两个都算漏检）；
- 零件的一部分被高光切断，剩下的碎片面积不够或 IoU < 0.5。
下一步的改进方向写在最后（分水岭拆分 / 按类零件面积先验 / ROI）。**先把能出框的版本跑起来**，再优化召回。

# 3. 思路（为什么这么写）

## 功能① 检出零件：六步

```
① 转灰度            rgb1_to_gray（彩色才需要）
② 二值化            threshold(gray, 0, 120)          ← 手动阈值，不用自动（上面有实测对比）
③ 闭运算            closing_circle(region, 5)        ← 把高光切断的碎片连起来
④ 填孔              fill_up(region)                  ← 零件内部的小孔会干扰面积和特征
⑤ 拆块 + 面积过滤   connection + select_shape(area, 2000 ~ 60000)
⑥ 量特征            area_center / smallest_rectangle2 / circularity
```

**为什么第 3 步要闭运算**：金属零件在自然光下有高光，阈值切出来是"零件 + 洞"；
闭运算（先膨胀再腐蚀）能把中间的高光洞和小缝补上，同时不太改变外轮廓。

## 功能② 分类：长宽比 + 置信度

```csharp
if (ratio >= 1.5)              → 螺丝   // 实测螺丝中位 2.40
else if (ratio <= 1.3)         → 螺母   // 实测螺母中位 1.07
else                           → 存疑   // 1.3~1.5 之间说不准，出红框
```
**置信度 = 离判定边界有多远**（刚好卡线上 0.5 分，越远越高）→ "模棱两可"的零件自动拿低分。

**角度周期不一样**：螺丝一头一尾对称 → 归一化到 `[0,180)`；螺母正六边形每 60° 自重合 → `[0,60)`。
不做归一化的话，同一个姿态会报出好几个"不同角度"。

**为什么用 `smallest_rectangle2` 而不是水平外接矩形**：零件在盘子上是随便转的，
最小外接矩形**跟着零件转**，量出来的长宽比才是真实形状（水平框会把斜放的零件量成接近正方形）。

## 功能③ 画框：先画图像、再叠框

框不是"画在图像上"，而是**每次重画时先 disp 图像、再 disp 框**（就在步骤 2 的 `FitAndDraw()` 里）：

```csharp
window.DispObj(image);                                  // ① 图像
// ② 每个零件：
window.SetColor(螺丝绿 / 螺母蓝 / 存疑红);
window.DispRectangle2(part.Row, part.Col, part.Phi, part.Length/2, part.Width/2);   // 旋转框
window.SetColor("yellow");
window.SetTposition(...); window.WriteString($"{编号}{S/N} {角度}");               // 编号+类型+角度
```
这样窗口缩放、翻页、切图时，框都跟着图像一起重画，不会错位。
> 文字用 ASCII（`1S 45`）不用中文：HALCON 默认字体不一定有中文字形。

## 功能④ 检测放在哪一层

- 检测算法全在 **`Service/PartDetector.cs`**（**不依赖 WPF** → 可以脱离界面单独评估，我就是这么量出 F1 的）
- **VM** 只负责"调用检测器 + 把计数写进绑定属性"
- **View** 只负责"把结果画成框"

## 5.1 `Model/PartResult.cs` —— 新建

> 🏛 **类 `PartResult` + 枚举 `PartType`**（纯数据）

```csharp
namespace HelcWPF
{
    /// <summary>零件类别</summary>
    public enum PartType
    {
        Unknown = 0,   // 存疑 → 出红色框
        Screw = 1,     // 螺丝（标注里的 bolt）
        Nut = 2        // 螺母（标注里的 nut）
    }

    /// <summary>一个检出零件的结果（纯数据）</summary>
    public class PartResult
    {
        /// <summary>图内编号（1 开始，和图上画的编号一致）</summary>
        public int Index { get; set; }

        public PartType Type { get; set; }

        /// <summary>分类置信度 0~1（离判定边界越远越高）</summary>
        public double Confidence { get; set; }

        /// <summary>面积（像素）</summary>
        public double Area { get; set; }

        /// <summary>中心行（纵向）</summary>
        public double Row { get; set; }

        /// <summary>中心列（横向）</summary>
        public double Col { get; set; }

        /// <summary>最小外接矩形的方向角（弧度，-π/2 ~ π/2）</summary>
        public double Phi { get; set; }

        /// <summary>最小外接矩形长边（像素）</summary>
        public double Length { get; set; }

        /// <summary>最小外接矩形短边（像素）</summary>
        public double Width { get; set; }

        /// <summary>长宽比 = Length / Width（★ 主要分类特征：螺丝≈2.4，螺母≈1.07）</summary>
        public double Ratio { get; set; }

        /// <summary>圆度（备用特征：螺丝≈0.26，螺母≈0.78）</summary>
        public double Circularity { get; set; }

        /// <summary>归一化角度（度）：螺丝 180° 周期、螺母 60° 周期</summary>
        public double AngleDeg { get; set; }

        // ── 显示用 ──
        public string TypeText => Type switch
        {
            PartType.Screw => "螺丝",
            PartType.Nut => "螺母",
            _ => "存疑"
        };

        public string ShortTag => Type switch
        {
            PartType.Screw => "S",
            PartType.Nut => "N",
            _ => "?"
        };
    }
}
```

## 5.2 `Service/PartDetector.cs` —— 新建

> 🏛 **类 `PartDetector` + 类 `DetectorResult`** ｜ ⚠️ 不依赖 WPF，可以脱离界面单独评估

```csharp
using HalconDotNet;
using Serilog;

namespace HelcWPF
{
    /// <summary>一次检测的结果</summary>
    public sealed class DetectorResult : IDisposable
    {
        public List<PartResult> Parts { get; } = new();

        /// <summary>所有零件区域合成一个对象（画框、评估都用它）</summary>
        public HObject? Regions { get; set; }

        /// <summary>二值化用的阈值（调参时要看）</summary>
        public double Threshold { get; set; }

        /// <summary>过滤前的连通域个数（诊断用：太多说明被高光切碎了）</summary>
        public int RawCount { get; set; }

        /// <summary>检测耗时（毫秒）</summary>
        public double ElapsedMs { get; set; }

        public int ScrewCount => Parts.Count(p => p.Type == PartType.Screw);
        public int NutCount => Parts.Count(p => p.Type == PartType.Nut);
        public int UnknownCount => Parts.Count(p => p.Type == PartType.Unknown);

        public void Dispose()
        {
            Regions?.Dispose();
            Regions = null;
        }
    }

    /// <summary>
    /// 螺丝/螺母检测器。不依赖任何 WPF 类型 → 能在控制台里单独跑、单独评估。
    ///
    /// 现场条件（决定了这套参数）：固定机位俯拍、自然光、零件放在白色盘子上 → 零件比背景暗。
    /// 默认参数来自对 508Pic 标注数据的实测（40 张图扫参数 + 严格 IoU 评估）：
    ///   自动阈值          F1 = 0.270   ← 太差，切出来全是碎片
    ///   手动阈值 120 + 闭运算 5 → P=0.887 R=0.724 F1=0.798 分类 96.6%   ← 用这套
    /// </summary>
    public sealed class PartDetector
    {
        private static readonly ILogger Log = Serilog.Log.ForContext<PartDetector>();

        // ── 参数（后面"调参面板"再把它们做成可调）──

        /// <summary>二值化阈值：背景约 150、零件约 60~120 → 120 是实测最优点</summary>
        public double Threshold { get; set; } = 120;

        /// <summary>闭运算半径：把被高光切断的碎片连起来（5 是实测最优；太大相邻零件会粘一起）</summary>
        public double ClosingRadius { get; set; } = 5;

        /// <summary>面积下限：小于它当噪点（统计：最小螺母约 4800，留足余量）</summary>
        public double MinArea { get; set; } = 2000;

        /// <summary>面积上限：大于它当整块背景/粘连（统计：最大螺丝约 23000）</summary>
        public double MaxArea { get; set; } = 60000;

        /// <summary>长宽比 ≥ 它 → 螺丝（螺丝中位 2.40，10% 分位 1.46）</summary>
        public double ScrewRatioMin { get; set; } = 1.5;

        /// <summary>长宽比 ≤ 它 → 螺母（螺母中位 1.07，90% 分位 1.14）</summary>
        public double NutRatioMax { get; set; } = 1.3;

        public DetectorResult Detect(HImage image)
        {
            var result = new DetectorResult();
            var sw = System.Diagnostics.Stopwatch.StartNew();

            // ① 转灰度（彩色才需要）
            HObject gray = image;
            HOperatorSet.CountChannels(image, out HTuple channels);
            if (channels.I >= 3) HOperatorSet.Rgb1ToGray(image, out gray);

            // ② 二值化：零件比背景暗 → 取灰度 ≤ 阈值的像素
            HOperatorSet.Threshold(gray, out HObject binary, 0, Threshold);
            result.Threshold = Threshold;

            // ③ 闭运算：把高光切断的碎片连成一个零件（半径太大相邻零件会粘连）
            HOperatorSet.ClosingCircle(binary, out HObject closed, ClosingRadius);
            binary.Dispose();

            // ④ 填掉零件内部的小孔
            HOperatorSet.FillUp(closed, out HObject filled);
            closed.Dispose();

            // ⑤ 拆块 + 面积过滤
            HOperatorSet.Connection(filled, out HObject connected);
            filled.Dispose();
            HOperatorSet.CountObj(connected, out HTuple rawCount);
            result.RawCount = rawCount.I;

            HOperatorSet.SelectShape(connected, out HObject parts, "area", "and", MinArea, MaxArea);
            connected.Dispose();
            result.Regions = parts;

            // ⑥ 逐个量特征 + 分类
            HOperatorSet.CountObj(parts, out HTuple count);
            for (int i = 1; i <= count.I; i++)
            {
                HOperatorSet.SelectObj(parts, out HObject one, i);

                HOperatorSet.AreaCenter(one, out HTuple area, out HTuple _, out HTuple _);
                HOperatorSet.SmallestRectangle2(one, out HTuple row, out HTuple col, out HTuple phi,
                                                out HTuple l1, out HTuple l2);
                HOperatorSet.Circularity(one, out HTuple circularity);

                var part = new PartResult
                {
                    Index = i,
                    Area = area.D,
                    Row = row.D,
                    Col = col.D,
                    Phi = phi.D,
                    Length = l1.D * 2,
                    Width = l2.D * 2,
                    Ratio = l2.D > 1e-6 ? l1.D / l2.D : 99,
                    Circularity = circularity.D
                };

                Classify(part);
                result.Parts.Add(part);
                one.Dispose();
            }

            sw.Stop();
            result.ElapsedMs = sw.Elapsed.TotalMilliseconds;

            Log.Information("[检测] 阈值={Threshold:F0} 连通域={Raw} → 零件 {Total} 个（螺丝 {Screw} / 螺母 {Nut} / 存疑 {Unknown}），耗时 {Ms:F1} ms",
                result.Threshold, result.RawCount, result.Parts.Count,
                result.ScrewCount, result.NutCount, result.UnknownCount, result.ElapsedMs);

            return result;
        }

        /// <summary>
        /// 分类：细长 → 螺丝；方圆 → 螺母；中间地带 → 存疑。
        /// 置信度 = 离判定边界有多远（刚好卡线上 0.5 分），所以模棱两可的零件会自动拿低分。
        /// </summary>
        private void Classify(PartResult part)
        {
            double phiDeg = part.Phi * 180.0 / Math.PI;

            if (part.Ratio >= ScrewRatioMin)                       // 细长 → 螺丝
            {
                part.Type = PartType.Screw;
                part.Confidence = Clamp(0.5 + 0.5 * (part.Ratio - ScrewRatioMin) / ScrewRatioMin, 0, 1);
                part.AngleDeg = NormalizeAngle(phiDeg, 180);        // 螺丝一头一尾对称
            }
            else if (part.Ratio <= NutRatioMax)                    // 方圆 → 螺母
            {
                part.Type = PartType.Nut;
                double span = Math.Max(0.05, NutRatioMax - 1.0);
                part.Confidence = Clamp(0.5 + 0.5 * (NutRatioMax - part.Ratio) / span, 0, 1);
                part.AngleDeg = NormalizeAngle(phiDeg, 60);         // 正六边形每 60° 自重合
            }
            else                                                   // 1.3 ~ 1.5 之间：说不准
            {
                part.Type = PartType.Unknown;
                part.Confidence = 0.3;
                part.AngleDeg = NormalizeAngle(phiDeg, 180);
            }
        }

        private static double Clamp(double v, double min, double max) => v < min ? min : (v > max ? max : v);

        /// <summary>把角度归一化到 [0, period)，例如 -95° → 85°</summary>
        private static double NormalizeAngle(double degrees, double period)
        {
            double a = degrees % period;
            return a < 0 ? a + period : a;
        }
    }
}
```

/// <summary>★ 步骤3：跑一遍检测，把结果存下来给 View 画框</summary>
private void DetectCurrent()
{

    var result = _detector.Detect(CurrentImage);

    _lastResult?.Dispose();                          // 释放上一次的中间结果（区域对象）

    LastParts = result.Parts;

    PartsText = $"零件 {result.Parts.Count}（螺丝 {result.ScrewCount} / 螺母 {result.NutCount}"
              + (result.UnknownCount > 0 ? $" / 存疑 {result.UnknownCount}）" : "）");
}

private void ClearParts()
{
    _lastResult?.Dispose();
    _lastResult = null;
    LastParts = new List<PartResult>();
    PartsText = "-";
}

/// <summary>把检测结果画到窗口上：按类别上色的旋转框 + 编号 + 角度</summary>
private void RenderMarkings(HWindow window)
{
    var parts = _viewModel.LastParts;
    if (parts.Count == 0) return;

    window.SetDraw("margin");
    window.SetLineWidth(2);

    foreach (var part in parts)
    {
        window.SetColor(part.Type switch
        {
            PartType.Screw => "green",
            PartType.Nut => "blue",
            _ => "red"
        });

        // 最小外接矩形（跟着零件转的框，顺便能看出朝向）
        window.DispRectangle2(part.Row, part.Col, part.Phi, part.Length / 2, part.Width / 2);

        // 编号 + 类型 + 角度（ASCII，HALCON 默认字体不一定有中文字形）
        window.SetColor("yellow");
        window.SetTposition((int)Math.Max(0, part.Row - part.Length / 2 - 14),
                            (int)Math.Max(0, part.Col - part.Length / 2));
        window.WriteString($"{part.Index}{part.ShortTag} {part.AngleDeg:F0}");
    }

    window.SetLineWidth(1);
    window.SetColor("white");
}

## 6.1 严格评估（这是判断"准不准"的唯一客观办法）

**关键：不能用"肉眼看着差不多"，要用 IoU**。匹配规则：
检出区域的**水平外接矩形** 与 标注框 求 IoU，IoU ≥ 0.5 才算命中（一个框只匹配一次）。

```csharp
// 检出框的水平外接矩形（和标注框同类型才能算 IoU）
HOperatorSet.SmallestRectangle1(one, out HTuple r1, out HTuple c1, out HTuple r2, out HTuple c2);

// IoU
static double Iou(double ac1, double ar1, double ac2, double ar2,
                  double bc1, double br1, double bc2, double br2)
{
    double ic1 = Math.Max(ac1, bc1), ir1 = Math.Max(ar1, br1);
    double ic2 = Math.Min(ac2, bc2), ir2 = Math.Min(ar2, br2);
    double inter = Math.Max(0, ic2 - ic1) * Math.Max(0, ir2 - ir1);
    double union = (ac2 - ac1) * (ar2 - ar1) + (bc2 - bc1) * (br2 - br1) - inter;
    return union <= 0 ? 0 : inter / union;
}
```

# 7. 常见坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 框特别碎、一个零件好几个框 | 用了自动阈值（`binary_threshold`）→ 切出的是高光边缘 | 改**手动阈值 120**（实测 F1 从 0.27 → 0.79） |
| 两个零件粘成一个框 | 闭运算半径太大 | 半径降到 5（或更小），也可以后续加"分水岭拆分" |
| 零件没框到 | 高光把零件切断，碎片面积 < 2000 被丢 | 调小 `MinArea`，或加大闭运算半径（两者要权衡） |
| 框画上了但翻页后错位 | 框没跟着重画 | 框必须画在 `FitAndDraw()` 里（先画图像再画框） |
| 内存一直涨 | `DetectorResult.Regions` 没释放 | 每次检测前 `_lastResult?.Dispose()`（VM 里已有） |
| 文字变成方块 | HALCON 默认字体没中文字形 | 用 ASCII（`1S 45`） |
| 评估结果和肉眼不一致 | 用"中心落在框里"当命中 → 太宽松 | 用 **IoU ≥ 0.5**（本页 6.1） |

# 8. 面试怎么说

> **检测是怎么做的？**
> 六步：转灰度 → 手动阈值二值化 → 闭运算 → 填孔 → 连通域 + 面积过滤 → 量形状特征。分类用最小外接矩形的长宽比：螺丝是平躺的细长件（实测中位 2.40），螺母接近方圆（中位 1.07），所以阈值取 1.5 / 1.3，中间地带判"存疑"出红框；置信度就是离边界多远，模棱两可的自动拿低分。
>
> **参数怎么定的？**
> 数据集自带 410 张图的标注，我没有靠眼睛调，而是写了个评估脚本：40 张图、283 个目标，用 **IoU ≥ 0.5** 严格匹配算 P/R/F1，再扫参数。结果两个发现：① HALCON 的自动阈值（`max_separability`）在这批图上很差，F1 只有 0.27——它切出来的是高光边缘导致零件被切成碎片；换成手动阈值 120 后 F1 到 0.79。② 闭运算在这里是必需的，半径 5 能把被高光切断的碎片连回一个零件，但再大就会把相邻零件粘一起，召回率反而下降。最终 P=0.887、R=0.724、分类准确率 96.6%，单张 2~3 ms。
>
> **现在的短板是什么？**
> 召回率 0.72，约四分之一的零件漏检，主要原因是相邻零件粘连和强高光导致的分割不全。改进方向：用距离变换 + 分水岭把粘连拆开；用每类零件的面积/尺寸先验做二次校验;  加 ROI 限定检测区域。这些都是"改参数/加算子"级别的工作，架构不用动——因为检测逻辑全在 `PartDetector` 这个类里，不依赖界面。
